## 👋 Hey, I'm Jeff

I'm a counselling psychologist who got hooked on writing code. Right now I'm studying software engineering at **Moringa School** in Nairobi, and I'm working on the space where the two worlds meet: tech that actually helps people feel better.

Before code, I spent years in psychology (assessment, CBT, trauma and crisis work, relationship counselling, workplace mental health). That background shapes how I build: I think about the person on the other side of the screen first.

- 🧠 Building mental-health tech for the Kenyan market
- 🌱 Currently learning Python, JavaScript, React and Flask
- 📈 Tinkering with algorithmic trading on the side
- ✍️ Writing fiction when I need a break from code
- 💼 Looking for remote / work-from-home opportunities
